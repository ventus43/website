# 씨앗책방 — 프로젝트 합의 요약

기준일: 2026-09-21. 이후 변경은 명시적으로 합의하고 이 문서에 반영한다.

## 서비스와 타겟

독서 모임의 작은 실천을 체크하고 캐릭터와 공동 정원을 함께 키우는 웹 서비스다. 핵심 대상은 **팀원 3명 + 지도사 1명**이며 개인 이용은 작은 맛보기 기능이다. 독서량·페이지 수보다 **실천했는지 여부**가 중요하다. 데스크톱 그룹 사용성을 우선하고 모바일은 후순위로 둔다.

## 유지할 UX 규칙

- 체크 항목은 **독서 · 감사일기 · 느낀점 나누기**다. 내용 입력 없이 체크만으로 완료한다.
- 세 항목은 독립적이며 다시 누르면 취소한다. 체크 직후 성장·상태 피드백을 제공한다.
- 쉬거나 연속 기록이 끊겨도 캐릭터 사망이나 누적 성장 손실 같은 처벌은 없다.
- 계기 → 간단한 실천 체크 → 성장 보상 → 기록·정원에 대한 애착으로 이어지는 경험을 지향한다.
- 9종 캐릭터의 정체성을 유지한다: 새싹이(시작), 잎싹이(꾸준함), 꽃봉이(이해·감정), 나무(지식·지구력), 부엉씨앗(사색·밤독서), 햇살씨앗(아침·규칙성), 이슬이(시·짧은 기록), 뿌리(재독·기초), 열매(완독·공유).

## 역할과 화면

| 역할/화면 | 핵심 범위 |
|---|---|
| 팀원 | 자신의 실천 체크, 캐릭터 선택·성장 및 기록 확인 |
| 지도사 | 그룹 생성·초대·구성원 관리, 팀원별 현황 확인 |
| 함께 보기 | 개별 상태와 공동 정원을 보여주는 읽기 전용 발표 화면 |
| 혼자 맛보기 | 브라우저에 저장하는 작은 개인 체험 |

**함께 보기에는 씨앗 조작이나 초대 코드·접속 키·계정 정보 등 관리 정보를 노출하지 않는다.**

## 구현 현황과 다음 범위

그룹 생성·초대 참여, 팀원 3명 제한, 실천 서버 저장, 지도사 관리, 계정 로그인·복구, 9종 캐릭터 시각화, 공동 정원과 함께 보기를 구현했다.

P1 완료: 1280×720에서 세 팀원의 체크 상태 9개를 첫 화면에 표시하고, 로그인 / 새 그룹 만들기 / 초대 참여 / 혼자 맛보기 경로를 분리했다. 초대 링크는 참여 화면, 로그아웃은 로그인 화면으로 연결한다.

P2 범위: 부분 실천과 전체 완료 표현 구분, 지도사 설정 접근 개선, 팀원 0명일 때 관리 버튼 비활성화, 가입 후 역할별 안내 문구 수정.

브라우저 검증과 자동 테스트는 실제 참가자 실험을 대신하지 않는다. 지도사 1명·팀원 3명 파일럿, 재연결·날짜 경계·긴 이름·키보드 흐름은 추가 검증한다. 챗봇은 카카오톡으로 정정했으나 현재 구현에서는 제외한다.

## 협업·개발 규칙

한국어로 사용자 중심 UX/UI 관점에서 소통한다. 기능 기획은 사용자 목표·문제 → 화면 구성 → 캐릭터·보상 → 예외·복구 순서로 정리한다. 요청된 Ponytail 방식에 따라 기존 코드·기본 기능을 우선 활용하고 불필요한 의존성을 추가하지 않는다. 기존 변경을 보존하고 구현 후 검증한다. 요청 범위 밖 기능과 운영 배포는 별도 합의한다.
