# 씨앗책방 그룹 프로젝트

캐릭터 시각화: 9종 SVG 캐릭터를 개인 체험, 팀원 화면, 지도사 관리 및 함께 보기에 적용했습니다. 누적 체크 0~14/15~29/30~44/45개 이상에서 씨앗·새싹·풍성한 잎·책을 든 완성 모습으로 변합니다. 45개 이후 성장 수치는 계속 증가하지만 외형은 완성 모습으로 유지됩니다. 오늘 체크가 있으면 반짝임과 짧은 등장 효과를 표시하며 모션 감소 설정을 지원합니다. 정원에는 팀원 3자리와 이름을 표시합니다. 미리보기: `/group_project/visual-preview.html` (예시 데이터, 실제 기록 변경 없음). 검증: `node group_project/garden-check.cjs`.

지도사는 **초대 링크 복사**로 팀원용 링크를 전달할 수 있습니다. 팀원은 링크를 열고 이름만 입력하면 참여할 수 있으며, 초대 코드는 자동 입력됩니다. 초대 정보는 URL fragment로 전달하고 참여 성공 후 주소에서 제거합니다. 참여 전 새로고침해도 초대 코드는 유지됩니다. 로컬 주소(127.0.0.1)는 다른 기기에서 접근할 수 없으므로 실제 공유에는 배포된 서비스 주소가 필요합니다. 링크 생성 검증: `node group_project/invitation-check.cjs`.

지도사 화면의 **함께 보기**는 화면 공유·모니터 표시용 읽기 전용 화면입니다. 팀원별 세 항목 완료 상태, 캐릭터·성장 단계, 그룹의 오늘/누적 실천과 정원을 표시합니다. 씨앗 선택·체크 조작, 초대 코드, 개인 접속 키는 표시하지 않습니다. 15초 자동 갱신하며 연결 실패 시 마지막 기록임을 안내합니다. `관리 화면으로 돌아가기` 또는 Esc로 닫습니다. 별도 공개 URL은 생성하지 않습니다. 참여 화면에서 팀원에게 지도사가 모임 중 함께 보기로 현황을 보여줄 수 있음을 안내합니다.

함께 보기 집계 검증: `node group_project/presentation-check.cjs`.

별도 설치와 빌드가 없는 첫 구현입니다. `index.html`을 열거나 저장소 루트에서 `python3 -m http.server 8080` 실행 후 `/group_project/`로 접속하세요.

- 독서, 감사일기, 느낀점 나누기: 각각 내용 입력 없이 체크/취소
- 9종 캐릭터 선택, 누적 체크 성장, 최근 7일 기록
- 모임 이름 설정, 개인 맛보기 전환
- localStorage로 같은 브라우저에 저장. 작성량에 따른 추가 보상 없음

그룹 서버 연결: 저장소 루트에서 `python3 group_project/dev_server.py` 실행 후 http://127.0.0.1:8080/group_project/ 접속. Flask가 필요합니다(`api/requirements.txt`). 정적 서버로는 개인 체험만 가능합니다.

지도사가 모임을 생성하고 초대 코드를 팀원에게 전달합니다. 팀원 정원은 3명이며 지도사 1명은 별도입니다. 지도사는 오늘 체크, 최근 7일 현황, 팀원별 캐릭터와 성장 단계를 조회하고 팀원 기록을 변경할 수 없습니다. 팀원은 자신의 세 항목을 독립적으로 체크하고 9종 캐릭터를 선택합니다. 선택은 서버에 저장되어 다른 기기에서 같은 접속 키로 접속해도 유지됩니다. 누적 체크 15개마다 성장 단계가 올라가며 체크 취소는 합계에 반영됩니다. 기록 날짜는 한국 시간입니다. 열린 화면은 15초마다 다른 기기의 변경을 가져오며 탭 복귀 시에도 갱신합니다. 연결 오류 시 마지막 확인 기록임을 표시합니다.

그룹 생성·참여 후 **계정과 그룹 관리 → 현재 구성원 계정 등록**에서 아이디(소문자·숫자·밑줄 4~32자)와 비밀번호(10~128자)를 등록합니다. 이후 아이디 로그인으로 같은 구성원 기록에 재접속합니다. 새 로그인은 이전 접속 키를 무효화합니다. 계정은 현재 한 그룹의 한 구성원에 연결됩니다.

등록 시 한 번 표시되는 복구 코드를 따로 보관하세요. **비밀번호 복구**에 아이디·새 비밀번호·복구 코드를 입력하면 재접속되며 새 복구 코드가 발급됩니다. 이전 복구 코드는 재사용할 수 없습니다. 지도사는 자기 복구 코드를 보관해야 하며 이메일 복구는 지원하지 않습니다. 기존 개인 접속 키도 계정 등록 전 진입 수단으로 계속 지원합니다.

지도사는 그룹 이름 변경, 초대 코드 재발급, 팀원 복구 코드 발급, 탈퇴 처리를 할 수 있습니다. 팀원 복구 코드 발급 시 기존 비밀번호·접속 키·복구 코드가 무효화됩니다. 팀원이 본인의 아이디와 새 복구 코드로 비밀번호를 설정해야 합니다. 탈퇴한 팀원의 기록은 보존되지만 그룹 현황·로그인에서 제외되며 정원이 반환됩니다. 탈퇴 취소 UI와 여러 그룹 계정은 후속 기능입니다.

비밀번호는 PBKDF2 해시, 접속·복구 코드는 SHA-256 해시로 저장합니다. 로그인·복구 시도 제한은 SQLite에 저장하므로 서버 프로세스 간 공유됩니다(아이디당 15분 10회, 접속 IP당 100회). 프록시 IP 헤더는 신뢰하지 않으므로 운영 프록시 구성에서 IP별 제한을 확인해야 합니다. 신규 테이블을 추가하며 기존 그룹·체크 데이터를 변경하지 않습니다. 캐릭터는 임시 이모지입니다.

기존 Flask API에 `/groups` 라우트를 등록했습니다. 운영 DB는 정적 배포 경로 밖 `/home/ubuntu/report/data/seed-groups.sqlite3`이며 `SEED_GROUP_DB`로 변경할 수 있습니다. 실제 배포 전 서버 프로세스의 해당 경로 쓰기 권한과 백업을 설정하세요. 로컬 서버 기본 DB는 `~/.local/share/seed-bookstore/groups.sqlite3`입니다. 이번 작업은 배포하지 않습니다.

계정·관리 검증: `cd api && python3 test_seed_accounts.py`.
